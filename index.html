Projeto de Conclusão · Ciência de Dados (CEUB) Dataset Público Olist KDD · Power Query · DAX

Análise Estratégica do E-commerce Brasileiro

Projeto acadêmico desenvolvido para a disciplina de Ciência de Dados do CEUB a partir dos datasets públicos do Olist. Todo o pipeline analítico seguiu o processo KDD, com tratamento e modelagem via ETL no Power Query e construção de métricas e indicadores executivos com inteligência DAX.

Base Analisada: 99,4 mil pedidos (Olist)
Etapas: KDD, ETL (Power Query) & DAX
Instituição: CEUB

Insights Estratégicos do Projeto

Operações & SLA

Eficiência Logística

97,02%

Taxa de entrega concluída em uma base de 99,4 mil pedidos, evidenciando alta capilaridade e confiabilidade operacional no cumprimento do ciclo de entrega.

Meios de Pagamento

Hegemonia do Crédito

78% · R$ 12,1 Mi

O Cartão de Crédito concentra 78% do faturamento (totalizando R$ 12,1 Mi), reforçando o papel do parcelamento na viabilização de compras no comércio eletrônico brasileiro.

Estratégia Comercial

Decisão Estratégica (Cross-selling)

> R$ 160

Equilíbrio entre volume de vendas e tickets altos (> R$ 160), apontando oportunidades de cross-selling e recomendações complementares para elevar o valor médio por pedido sem perder conversão.
